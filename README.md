# Odoo Tutor Modules

This repository holds all the modules required to build the Odoo Tutor app.

## Feature flags

Set `ODOO_TUTOR_ENABLE_SKIP_STEP=true` in the Odoo server environment to show
the exercise skip button. The flag is disabled by default. Accepted enabled
values are `1`, `true`, `yes`, and `on` (case-insensitive); restart Odoo after
changing it.
