Odoo Tutor

Odoo Tutor adds an in-context tutoring sidebar to Odoo. Ask questions while working and receive step-by-step guidance from your configured Odoo Tutor service.

Learn while you work

  • Open the tutor chat from the Odoo backend.
  • Ask for an exercise, ask about the module you are in, or whatever you can imagine.
  • Receive contextual hints and guidance during supported exercises.
  • Skip an exercise step when you are stuck.
  • Send feedback on tutor responses.

Configuration and requirements

Set the tutor service WebSocket URL in Odoo settings. Odoo registers each installation automatically and keeps its service credential on the server. You can optionally configure your own language model key.
