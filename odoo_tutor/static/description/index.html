Odoo Tutor

Odoo Tutor adds an in-context tutoring sidebar to the Odoo backend. Ask questions while working and receive step-by-step guidance from your configured Odoo Tutor service.

Learn while you work

  • Open the tutor chat from the Odoo backend.
  • Receive contextual hints and guidance during supported exercises.
  • Skip an exercise step when you are stuck, if the administrator enables the option.
  • Send feedback on tutor responses.

Configuration and requirements

Configure the tutor service WebSocket URL and API key in Odoo Settings. The skip option is controlled by the ODOO_TUTOR_ENABLE_SKIP_STEP environment variable. This add-on requires a compatible Odoo Tutor backend and the Odoo apps listed as dependencies.
