Odoo Tutor

Odoo Tutor adds an in-context tutoring sidebar to the Odoo backend. Users can ask questions while working and receive guidance from a separately deployed Odoo Tutor service.

Learn while you work

  • Open the tutor chat from the Odoo backend.
  • Receive contextual hints and guidance during supported exercises.
  • Continue or skip an exercise step when the administrator enables that option.
  • Send feedback on tutor responses.

Configuration and requirements

Configure the tutor service WebSocket URL and API key in Odoo Settings. This add-on requires a separately deployed, compatible Odoo Tutor backend and the Odoo apps listed as its dependencies. The backend service is not included in this add-on.
